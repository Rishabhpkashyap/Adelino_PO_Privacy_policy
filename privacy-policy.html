Privacy Policy

Adelino PO - Educational Trading Simulator

Last Updated: February 22, 2026

Introduction

Adelino PO - Educational Trading Simulator ("the Extension") is committed to protecting your privacy. This Privacy Policy explains how the Extension handles data when you use it for educational purposes.

Data Collection

What We DO NOT Collect

The Extension does NOT collect, transmit, or share any of the following:

  • Personal information
  • Trading data or account credentials
  • Browsing history
  • Financial information
  • User behavior analytics
  • Cookies or tracking data
  • Any data to external servers

What We Store Locally

The Extension stores the following data ONLY in your local browser storage:

  • Your customization preferences (account level, achievement settings)
  • Simulated transaction entries you create for demonstrations
  • Simulated trade history entries for educational purposes
  • UI toggle states (which features are enabled)

Important: All data is stored locally on your device using Chrome's storage API. This data never leaves your computer and is not accessible to the developers or any third parties.

Data Usage

The locally stored data is used exclusively to:

  • Remember your simulation settings between sessions
  • Display your customized demo account appearance
  • Show your simulated transaction and trade history
  • Maintain your UI preferences

Data Sharing

We do not share any data because we do not collect any data. All information stays on your local device.

Third-Party Access

The Extension does not:

  • Send data to any external servers
  • Use third-party analytics services
  • Include advertising networks
  • Connect to any APIs except the local browser storage

Permissions Explanation

The Extension requires the following permissions:

activeTab

Purpose: To interact with the Pocket Option demo platform page

Usage: Applies visual customizations to the demo account display

Data Access: Only accesses the active tab when you use the Extension

scripting

Purpose: To inject educational simulation features into the demo platform

Usage: Adds simulation controls and customization options

Data Access: Only modifies visual display, does not access account data

storage

Purpose: To save your simulation preferences locally

Usage: Stores your customization settings on your device

Data Access: Only stores data you explicitly configure

tabs

Purpose: To reload the page when applying new settings

Usage: Refreshes the demo platform to show updated simulations

Data Access: Only reloads the active tab, no data collection

host_permissions (pocketoption.com)

Purpose: To work specifically with Pocket Option demo accounts

Usage: Applies educational simulations to the demo platform

Data Access: Only modifies visual display for educational purposes

Data Security

Since all data is stored locally on your device:

  • Data is protected by your browser's security measures
  • Data is isolated to your Chrome profile
  • Data can be cleared at any time by removing the Extension
  • No transmission means no interception risk

User Control

You have complete control over your data:

View Your Data

  • All settings are visible in the Extension popup
  • Simulated entries can be reviewed in the platform interface

Delete Your Data

  • Click "Reset Extension" in the popup to clear all data
  • Uninstall the Extension to remove all stored data
  • Clear Chrome extension data via browser settings

Export Your Data

  • Data is stored in Chrome's local storage
  • Can be accessed via Chrome DevTools if needed for backup

Children's Privacy

This Extension is designed for educational purposes and does not knowingly collect data from users of any age. Since no data is collected or transmitted, there are no age-related privacy concerns.

Changes to This Policy

We may update this Privacy Policy to reflect changes in the Extension or legal requirements. Updates will be posted with a new "Last Updated" date. Continued use of the Extension after changes constitutes acceptance of the updated policy.

Educational Use Disclaimer

This Extension is intended for educational purposes only:

  • Designed for creating tutorials and educational content
  • Not intended for use with real trading accounts
  • Does not interact with real financial data
